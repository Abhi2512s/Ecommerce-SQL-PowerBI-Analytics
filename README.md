# E-Commerce Sales & Customer Analytics Dashboard

## Project Overview
This project combines PostgreSQL, SQL analytics, and Power BI to analyze e-commerce sales, customer behavior, delivery performance, and product category revenue.

The project demonstrates end-to-end analytics workflow:
- Data storage in PostgreSQL
- SQL querying and data transformation
- Analytical dataset creation
- Interactive dashboard development in Power BI

---

## Tools & Technologies
- PostgreSQL
- SQL
- Power BI
- DAX

- JOINs

- CTEs (Common Table Expressions)
- Window Functions

- Aggregations
- Date Functions

## Dashboard Features
### KPI Cards
- Total Revenue
- Total Orders
- Average Order Value
- Delayed Orders %

### Visualizations
- Monthly Revenue Trend
- Top Product Categories
- Customer Segment Distribution
- Order Delivery Status

## Project Workflow
Raw CSV Data → PostgreSQL → SQL Analysis → Analytical Datasets → Power BI Dashboard
